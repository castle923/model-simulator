# 소형 공장 · 통행권 실험

`model simulator`의 **소형 공장 · 통행권 실험** 탭에서 실행한다. 기존 **작업 공간**의 지도, 편집 기능, 저장 키와 분리된 웹 실험이다.

## 첫 실행

1. **기본 소형 공장 불러오기**를 누른다.
2. 아래 명령을 기체별로 선택하여 입력하고 **명령 확인 → 선택 기체 작업 큐에 추가**를 누른다.
3. **공장 시계 시작 / 계속**을 누른다. 시계 실행 중에도 다른 기체의 명령을 추가할 수 있다.

| 기체 | 입력 예시 | 목적지 |
|---|---|---|
| R1 | `R1 작업장 B로 이동해줘` | B / P2 |
| R2 | `R2 작업장 A로 이동해줘` | A / P1 |
| R3 | `R3 작업장 D로 이동해줘` | D / P4 |
| R4 | `R4 작업장 C로 이동해줘` | C / P3 |

각 작업장과 주차장은 같은 칸을 공유한다. 기본 배치에서 B/P2에는 R2가 있으므로 R1에 B 이동만 명령하면 기다리는 것이 정상이다. R2에도 출발 명령을 주어야 한다. 기체는 작업 완료 후 현재 위치에서 대기한다. `R1 주차해줘`, `R3 충전해줘`도 지원하며 문장의 기체 ID와 선택한 기체가 일치해야 한다. 임의 Python 실행이나 일반 자연어 전체를 이해하는 AI는 아니다.

## 구현한 실험 규칙

| 항목 | 동작 |
|---|---|
| 실제 축척 | 제조사 명목 차체 길이 208.74 × 폭 165.83 × 높이 127.05mm. 사용자 조립 기체의 실측값은 아니다. |
| 작은 공장 | 3×2m의 고정 배치, 폭 24cm의 한 대 전용 통로. 기존 자유 배치 지도 크기는 별도다. |
| 전진 전용 | 직선·원호, 속도·가속·제동·최소 회전 반경 제한. 후진·횡이동·제자리 회전 금지. |
| 통행 허가 | 양쪽 QR은 같은 AISLE-1을 식별한다. 입구 밖에서 정지·요청하고 통로와 출구 공간의 확정 허가를 받아 진입한다. 같은 방향도 한 대씩 통과한다. |
| 해제 | 차체·적재물 후미가 통로를 벗어난 후 통로를 해제한다. 출구 공간은 별도로 확인하여 해제한다. |
| 실행 중 명령 | 다른 기체의 위치·작업·시계·예약을 초기화하지 않고 선택 기체의 큐에 추가한다. |
| 통신 고장 | 지연·유실·중복·단절과 재시작을 가상 메시지 버스로 시험한다. 점유 불명 UNKNOWN을 자동으로 FREE로 바꾸지 않는다. |
| 정면 화면 | 선택 기체의 동일 위치·방향·시간으로 그리는 합성 2D 화면. 실물 카메라 영상은 아니다. |
| 기록 | 이벤트·설정 JSON 다운로드. 가상 배터리는 소수점 두 자리로 표시한다. |

기본 최대 속도 0.16m/s, 회전 반경 0.20m, 가속 0.20m/s², 제동 0.30m/s²는 **실측되지 않은 가상 설정**이다. Raspbot의 실제 메카넘 구동을 자동차형 전진 제약으로 제한한 실험이다. `reactionTime`은 현재 실행기에 적용되는 지연 모델이 아니다. 고장 감지 후 다음 내부 tick부터 감속하며 실제 센서·통신·제어 반응시간을 검증하지 않았다.

## 대기·고장과 저장

- 다른 기체가 목적지·이동 구역을 점유하면 대기한다. 자동으로 미명령 기체를 옮기지 않는다.
- 전진 경로를 찾지 못한 정적 구조는 작업 오류로 보고한다. 탐색 실패는 가능한 모든 경로가 없다는 수학적 증명과 다르다.
- 통신 복구 후 **재기동·점유 복구 실험**의 명시적 상태 확인을 사용한다. 정지와 점유 소유자가 일치해야 복구한다. 이는 시뮬레이션의 실제 위치를 사용하는 운영자 확인이며 실물 센서 복구가 아니다.
- 탭을 바꾸면 시계만 멈추고 위치·작업·예약은 유지한다.
- 브라우저에는 **설정만** 저장한다. 진행 중 새로고침하면 이전 실행 상태는 복원하지 않으며, 새 실험 시작을 명시적으로 확인하기 전에는 실행을 차단한다.
- 기존 작업 공간은 `userScene2`, 이 실험은 별도 저장 키를 사용한다. 팀원별 브라우저에 저장되며 지도와 실험 상태의 자동 실시간 공동 편집은 아니다.

## 검증과 적용 한계

자동 시험:

```text
node --experimental-strip-types scripts/test-industrial-runtime.mjs
node --experimental-strip-types scripts/test-industrial-protocol.mjs
```

정상 시험은 실제 차체의 최대 통로 점유 1대, 전역 안전장치 개입 0회를 요구한다. 안전장치가 충돌을 막았다는 사실만으로 통행 프로토콜 성공을 주장하지 않는다. 네 대의 교차 명령, 반복 작업, 실행 중 명령, 메시지 고장, 오래된 토큰, 후미 이탈과 재시작을 시험한다.

이 구현은 고정 배치의 웹 논리 실험이다. 임의 공장의 완주·공정성, 실기체 안전, 실제 QR 판독·MQTT·ROS2·Pi5, Unity/CARLA/Gazebo 엔진 연결, 유리·굴곡의 센서 오인식, 자동 PPE 감시와 30% 배터리 충전 정책은 검증 완료 범위에 포함하지 않는다. 실제로 연결되지 않은 기능을 연결 완료로 표시하지 않는다.
