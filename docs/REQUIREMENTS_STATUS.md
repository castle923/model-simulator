## 검증 경계

`test-astra-scene-invariants.mjs`는 편집 지도에서 전체 계획 원호/직선의 물리적 여유, 매 tick 이동거리/각속도, 기체 간격, 불변 Scene 및 예약 해제를 검사한다. 특정 회귀 입력 검증이며 임의 지도의 경로 존재를 증명하지 않는다. 기본 실행은 내장 생성 지도만 사용한다. 선택적으로 명시한 첫 CLI 인수의 지도 JSON을 검사할 수 있다. 개인 편집 입력은 공개 소스에 지도 내용이나 경로를 넣지 않는다.

새 배포에서는 메인 경로 `/`와 팀 경로 `/legacy`를 모두 확인해야 한다. 팀 링크는 `/legacy`를 가리킨다. 엔진/센서/실물/다중 PC WebRTC 결과는 확인하지 않은 상태에서 완료로 표시하지 않는다.

## 2026-10-14 로컬 동적 주행 변경

이번 변경은 로컬 소스·빌드·검사에만 적용했다. 배포 여부/공개 사이트 반영을 주장하지 않는다. `docs/DYNAMIC_NAVIGATION.md`에 관측과 전역 안전장치의 구분, 시도 예산, 임무 보존 및 실패 한계를 기록했다. 예전 gate/주차 가상 장애물·600초 사전 실행 판정은 최신 구현의 계약이 아니다.
