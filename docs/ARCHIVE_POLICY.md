복사일: 2026-10-19. 추가자료는 복사본 연구/인계 폴더와 선택된 검증 증거입니다. 대화 전체 복원본이나 없는 데이터셋의 저장본은 아닙니다.

제외: `.git`, `.env*`, 연결인증·카메라세션·로컬DB·편집지도·녹화, `node_modules`, 빌드산출물, 임시캐시/로그, 사용자개인미디어. `outputs` 전체를 올리지 않고 검사JSON/배포JSON/공개시연화면만 선택했습니다. 외부문서 HTML/제조사 이미지 원본은 출처와해시만 보존했습니다.

조정한 파일: 새 README·AGENTS·개발/CI문서, `.gitignore` 캐시제외 보강. `.openai/hosting.json`은 DB/R2 바인딩 이름만 남기고 기존Site ID를 제거했습니다. 이는 운영자원 연결이나 새배포가 아닙니다. 기존README는 역사문서로 별도 보존합니다.

`.gitattributes`의 `* -text`는 Windows/Linux 복제 시 줄바꿈 자동변환을 방지하여 초기 보존 해시를 유지합니다. 기존 혼합 줄바꿈을 보존하며 코드/문서 변경 시 팀과 형식을 합의하세요.
