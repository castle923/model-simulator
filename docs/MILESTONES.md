# 마일스톤
완료는 명시된 웹/보존 범위이며 실물 로봇 목표 달성을 뜻하지 않습니다. GitHub Milestones와 연결된 Issue가 실제 진행판입니다.
| 단계 | 이름 | 상태 | 완료/수용 조건 |
|---|---|---|---|
| M1 | 소스·연구·검증 보존 | 이번 보존 작업 | 최신 소스·조사·인계·증거·무결성 목록 및 GitHub 읽기 확인 |
| M2 | 공통 장면·Free Space | 웹 구현 | 단일/다중·객체 편집·JSON·기체 삭제/추가·원자적 검증 |
| M3 | 주행·교통·공용 충전 | 제한 있는 웹 구현 | 동적 회피·전진 곡선·통행권·안전대기 회귀; 혼잡 완주 개선은 열림 |
| M4 | 기체·장비·임무 커스텀 | 웹 구현 | 프리셋·개별속도·카메라/팔·고급명령·dry-run export |
| M5 | 카메라·UI·실험 피드백 | 웹 구현/부분 검증 | 합성 시점·16:9줌·설정·force실험; 실제USB 검증은 열림 |
| M6 | 팀 협업·서버·엔진 어댑터 | 부분/미연결 | legacy 통합, DB경계, 공유영상/댓글, NAT/TURN, 실제엔진 handshake |
| M7 | CI·회귀·릴리스 재현 | 이번 보존 작업 | 실제 Actions 통과, 증거 보관, 배포 없음 확인; 실물게이트 별도 |
| M8 | ROS2·Pi5·PPE·실물 시연 | 향후 | 환경 통일, 센서/모델 실측, watchdog/비상정지, 주행 실험; 안전모전달은2차 |

팀의1차 목표는 장애물을 회피하여 목적지를 완수하고 복귀하는 자율주행입니다. 수치 목표는 팀 협의 전입니다. 2차 목표인 양팔 안전모 전달의 실제 집기·가반하중·시각 추적은 별도입니다. IoT 홈 키트는 본 프로젝트의 기본 구성이 아니며 이후 프로젝트용입니다.
