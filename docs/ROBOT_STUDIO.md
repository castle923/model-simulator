# 기체 커스텀 · 고급 시뮬레이션 사용 안내

## 작업 흐름

| 순서 | 화면 | 하는 일 |
|---|---|---|
| 1 | 운영 대시보드 | 기체별 크기·속도·장비·배터리 확인 후 구성 편집 |
| 2 | 기체 커스텀 | 프리셋/형상/치수/개별 속도 선택, 카메라·팔·관절 구성 |
| 3 | 적용 대상 | Free Space 또는 소형 공장과 대상 기체를 선택해 구성 적용 |
| 4 | Free Space · 통합 주행 | 서로 다른 종류를 같은 장면에 배치하고 주행 시작 |
| 5 | 고급 임무 · 주행 규칙 | 기체별 경유지, 목표, 운동 모델, 완료 후 충전/목표 대기 설정 |

설정은 적용 전까지 초안이다. 여러 기체를 선택하면 동일 초안을 선택 기체에 적용한다. 기체마다 다르게 설정하려면 각각 선택해 적용한다. 지도 변경·기체 설정 적용은 Free Space 실행 경로를 초기화하고 Worker가 새 경로를 확인한다. 소형 공장의 설정은 작업·예약이 없는 정지 상태에서만 반영하며 현재 위치·시계를 보존한다.

## 확장한 자유도

| 항목 | 범위 |
|---|---|
| Free Space 크기 | 가로·세로 2~30m |
| Free Space 기체 | 최대 8대 R1~R8. 추가 시 부족한 충전 대기점은 빈 공간에 생성, 실패 시 전체 추가 거부 |
| 경유지 | 기체별 최대 40개, 순서 변경·삭제·지도 드래그·JSON 편집 |
| 완료 행동 | `charge`는 충전·이탈, `stay`는 목표에서 완료·대기 |
| 차체 | 라즈봇, AMR, 지게차형, 무한궤도형, 사용자 기체, TurtleBot3 Burger/Waffle Pi, 원형 AMR |
| 형상 | 직사각형 / 원형·타원형, 길이·폭·높이 조절 |
| 개별 속도 | 커스텀 기체별 0.02~2m/s. 소형 공장은 해당 실험의 더 좁은 허용 범위 검증 |
| 카메라 | 기체별 최대 4대, 활성화·장착 XYZ·yaw/pitch·화각·거리·해상도 |
| 팔 | 기체별 최대 2개, 좌/우/중앙, 접힘·도달거리·가상 하중·관절 최대 6개 |
| 보관함 | 현재 브라우저 최대 20개. JSON으로 내보내 다른 사람에게 전달 |

큰 기체·펼친 팔·돌출 카메라는 주행 안전 외곽을 넓힌다. Free Space는 보수적 외접원, 소형 공장은 보수적 사각 외곽으로 검사한다. 타원 외형은 근사 표현이며 경로의 정확한 타원 접촉 해석은 아니다. 모델명만으로 해당 기체의 차동 구동·동역학·실물 제어를 구현한 것으로 보지 않는다. 전진 전용 자동차형과 가상 전방향 운동 모델은 별도 선택한다.

소형 공장 · 통행권 실험은 3×2m, 24cm 통로, 네 대의 별도 검증 장면이다. 큰 AMR·Waffle Pi 기본 폭 등은 이 통로에 맞지 않으면 거부한다. 큰 공장·다양한 기체의 공통 운행은 Free Space에서 구성한다.

## TurtleBot 기본값의 출처

[ROBOTIS 공식 TurtleBot3 사양](https://emanual.robotis.com/docs/en/platform/turtlebot3/features/)의 명목값: Burger 138×178×192mm/최대 병진 속도0.22m/s, Waffle Pi 281×306×141mm/0.26m/s. Burger 기본 사양에는 카메라가 없으므로 프리셋도 카메라 없음으로 시작하며 직접 추가할 수 있다. Waffle Pi는 카메라 1개를 구성한다. 모델 외형·센서 장착 위치·팔·일반 AMR 프리셋은 웹 시연용 근사이며 제조사 CAD·실측 장비 교정이 아니다.

## 장착 카메라와 화면

- 지도 우측 상단의 합성 화면은 선택 기체·장착 카메라의 위치, yaw/pitch, 높이, 화각, 거리, 해상도를 같은 장면 데이터로 사용한다. 감지 계산은 활성 카메라들의 2D 수평 시야 합집합이며 영상 AI나 3D 수직 감지 모델이 아니다.
- 관찰 기체와 장착 카메라를 선택한다. 카메라가 없거나 비활성화되면 합성 영상과 실제 장치 연결 버튼에 해당 상태를 표시한다.
- 실제 PC 웹캠은 **영상 장치 목록 확인 → 선택 장착 카메라에 웹캠 연결**을 사용한다. HTTPS 또는 localhost와 브라우저 권한이 필요하다. 사용자 클릭 전에는 카메라를 시작하지 않는다.
- 실제 영상은 선택한 작업 공간/기체/장착 카메라 ID와 연결해 별도 표시한다. 기체·카메라·구성을 바꾸거나 화면을 벗어나면 스트림을 종료한다. 늦게 도착한 권한 응답도 이전 기체 영상으로 붙지 않는다.
- 이것은 브라우저가 실행되는 PC의 웹캠이다. Pi5 원격 카메라, 실제 기체 위치·센서 시간과의 동기화, PTZ 회전 제어, 팀원 영상 전송은 별도 연결이 필요하다. 합성 yaw/pitch를 바꾸어도 실제 웹캠을 회전시키지 않는다.
- 실제 USB 카메라가 없는 검증에서는 모의 스트림 수명주기만 검증한다. 실제 화질·지연·장치 호환은 연결한 장비에서 확인해야 한다.

## 임무 편집과 저장

고급 임무는 `advanced-mission-1` JSON이다. `baseRevision`이 현재 지도 버전과 다르면 초안을 보존한 채 적용을 거부한다. 운동 모델, 최소 반경, 목표 층, 경유지, 완료 행동을 편집한다. 적용하면 선택 기체를 목표 주행 임무로 교체한다. 안전모 집기·전달은 별도 바이브 임무 공간에서 작성하며, 해당 임무는 이후 목표·충전 순서를 사용한다.

JSON은 선언형 설정이며 임의 JavaScript/Python을 실행하지 않는다. 다운로드 Python/노트북은 교육용 설명이고 실제 모터·영상 AI·MoveIt·하중 물리를 실행하지 않는다. 지도·실행 기록·보관함은 브라우저 저장 공간에 보관되며 자동 공동 편집이나 서버 간 동기화가 아니다. 손상된 설정은 원문 복구 기능으로 보호한다.


## 화면 배치와 큰 지도 보기

작업공간 커스텀에서 밝은/어두운 테마, 글자 크기, 편집 패널 위치·폭·표시, 카드·코드·공유 안내·격자 표시를 지정한다. 화면 설정은 별도 브라우저 키에 저장하며 지도 버전·기체 위치·임무를 변경하지 않는다. 공장 크기 변경은 기존 객체의 경계를 검증한 후 적용한다. 빈 공장 기능은 랙·작업자 등 작업 객체를 제거하며 기체 구성·위치·충전/층 이동 시설을 유지한다. 되돌리기로 복원할 수 있다.

기본 지도 화면은 16:9이며 정사각형도 설정할 수 있다. 줌은 100~600%, 휠은 커서 기준 확대, Shift+드래그 또는 화면 이동 버튼은 지도 이동이다. 전체 지도 맞춤은 화면만 초기화한다. 선택 기체 위치 확대는 현재 기체 위치와 층으로 이동한다. 지도 집중 화면은 긴 상단 안내를 숨기고 지도·주행 조작에 집중한다. 확대된 화면의 편집 포인터는 같은 역변환을 사용한다. 확대·이동은 기체나 지도 데이터를 변경하지 않는다.

## 오류 해결 웹 실험

정상 주행은 기존 회피·충돌 정지·통로 예약을 유지한다. 별도 오류 해결 실험에서 예를 들어 `R1 충돌을 허용하고 목표로 직진해줘`를 입력하고 생성된 JSON을 확인하여 적용하면 선택 기체만 강제 직진한다. 같은 층 목표 주행/목표 대기이며 자동차형 제약도 해제한다. 다른 기체의 정상 안전장치는 유지한다. 지도 밖 좌표·잘못된 JSON·버전 충돌은 거부한다. 무제한 코드 실행 기능이 아니다.

강제 실험은 우회/충돌 정지/예약을 생략하여 원인과 대안을 비교하기 위한 기능이다. 안전 외곽이 침범한 고유 객체/기체 ID를 최대32개 기록하며 실제 접촉 센서 측정이 아니다. 종료 기록은 안전 주행 성공으로 판정하지 않는다. 의견과 실제 적용 JSON은 최대50건 브라우저에 보관하며 JSON 다운로드할 수 있다. 의견으로 자동 학습하거나 제품 코드를 자동 고치지는 않는다. 정상 복귀 버튼 또는 일반 임무 적용으로 강제 설정을 제거한다. 복귀 위치가 장애물과 겹치면 기존 배치를 수정해야 정상 모드가 검증된다. 강제 실험의 정상 Python/Notebook 내보내기는 거부한다.

## 검증 한계

8대의 서로 다른 기체를 목표 대기로 실행한 검증은 통과했다. 별도22×12m 혼잡 충전 배치에서는600초 가상 시간 후6대 완료,2대 안전 대기였다. 기체8대 지원이 임의 배치의 충전·작업 완주 보장은 아니다. 대기/정체는 배치·경유점·개별 임무 또는 명시적 실험으로 분석한다. 실제 Unity/CARLA/Gazebo, Pi5, 제조사 로봇, 실제 팔 역기구학/하중 물리는 연결하지 않았다.
