# 합성 센서를 이용한 동적 기체 우회 (로컬 변경)

2026-10-14. 웹 2D 시뮬레이션용 구현이다. 실제 영상/YOLO, Gazebo, ROS, 물리 로봇 연동이 아니다. 사용자 저장 지도를 자동 변경하지 않으며 예시 지도는 버튼을 클릭할 때만 적용된다.

## 동작

- 카메라와 같은 pose 및 수평 FOV(약 66.7도)로 3.6m 이내의 다른 기체 중심을 0.15초 간격으로 검사한다. solid 지도 사각형과 다른 기체의 2D 원형 몸체가 광선을 가린다. 카메라의 그림은 교육용 pinhole 표현으로 더 멀리 보일 수 있다. 센서는 렌더링 픽셀을 읽지 않는다. 낮은 물체도 2D에서는 가림으로 취급하는 보수적 근사다.
- 관측 위치/속도를 이용해 현재 위치와 0.4초 예측 위치에 동적 원형 장애물을 만들고 기존 경로 탐색기로 우회한다. 초록 원은 이번 관측, 점선은 기억이다. 과거 위치가 보이지만 비어 있으면 즉시 지우고, 가려진 기억은 마지막 관측 1.2초 후 만료한다. 지도 객체는 삭제하지 않는다.
- ID 순서를 이용해 한 기체가 공간을 확보하고 상대가 우회하도록 결정한다. 경로가 충돌할 때 감속/재계획하며, 우회가 없으면 기다린다. 단일 차선 추종, 넓은 교차/정면 조우와 4대 랙 구간을 검사했다. 비켜설 공간이 전혀 없는 양방향 단일 통로 등 모든 배치의 완주는 보장하지 않는다.
- 별도의 전역 시뮬레이션 안전장치는 센서에 안 보이는 기체도 포함해 이동 구간의 최소 간격 0.49m(자동차 추가 원호 여유 0.002m)를 검사한다. 안전 정지는 카메라 감지로 표시하지 않는다. 전방에 없던 위험 때문에 멈춘 홀로노믹 기체는 방향을 돌려 재관측할 수 있다. 자동차는 제자리 회전을 하지 않는다. 이것은 실기체 센서로 보장된 안전이 아니다.
- 우회한 선을 지도에 즉시 다시 그리고 기체 카드에 감지 ID, 재계획 횟수와 대기 원인을 표시한다. 실행 경로는 정적 원본 경로의 사본이므로 실행 종료 후 다시 시작할 때 누적되지 않는다.

## 임무와 성능

정적 계획은 원래 경유점, 목표, 안전모 집기/전달, QR/층 이동, 충전 대기/충전/이탈을 순서 있는 체크포인트로 보관한다. 홀로노믹 기체는 다음 체크포인트까지 교체하고 이후 경로를 유지한다. 자동차는 현재 pose에서 전진 원호로 남은 체크포인트를 다시 연결하여 접합 순간이동/후진을 피한다. 최초 목표 좌표를 별도로 보존해 재계획 반복에 따른 목표 드리프트를 막는다. 완료 액션·안전모 소유권·배터리를 초기화하지 않고 성공 시에만 전체 인덱스를 원자적으로 갱신한다.

전체 기체 중 재계획은 시뮬레이션 시간 0.35초마다 최대 한 번, 기체별 최소 0.9초 간격이다. 한 시도 전체의 탐색 노드 14,000개와 약 55ms 벽시계 예산을 공유한다(노드 64개마다 시간 확인, 사전 후보 구성 등 작은 부수 작업은 별도). 실패는 최대 4초까지 backoff하고 같은 관측 상태에서 6회 실패하면 관측이 바뀔 때까지 탐색을 중단한다. 자동차 탐색은 이진 heap을 사용한다. 정적 주차 후보는 최대 50개다. 제한 때문에 실제 가능한 경로도 탐색 실패로 안전 대기할 수 있다. UI 프레임이 실시간 제어 주기를 보장하지는 않는다.

고정 stage 위치와 다른 기체의 미래 주차/대기점을 필수 장애물로 만들지 않는다. Worker는 정적 임무 구간의 실행 가능성만 검증하며 다중 600초 사전 시뮬레이션으로 시작을 차단하지 않는다. 기존 lock 도형은 보존한다. 정적 장애물 사이 차체 중심의 횡방향 이동폭을 세 단면에서 검사해 0.55m 미만인 통로에만 배타 예약을 적용한다. 진입까지 연속 거리/속도로 선행 기체를 선정하며 1cm 차이도 순서와 무관하게 반영한다. 반대편 대기는 통로 끝 1.1m 전에서 정지하고, 소유 기체는 출구 여유 영역을 벗어날 때까지 예약을 보유한다. 고정 stage 경유점을 만들지 않는다. 자동 폭 판정은 직사각형 통로에 대한 보수적 근사다. 충전소와 가상 엘리베이터의 독점 소유권은 유지한다.

## 검사

`node scripts/test-dynamic-navigation.mjs [선택적 로컬 지도 JSON]`는 정면/교차 조우, 배열 역순, 4대, 정지 기체 실제 우회, 새 이동 기체 경로 진입, 단일 차선 추종, 센서/ghost, 실패 원자성, 자동차 곡률·전진, 목표 방문·충전·자원 해제·Scene 불변을 검사한다. `test-scene-local.mjs`는 넓은 lock 예약 생략과 실제 좁은 lock의 1cm 선행 진입을 별도로 검사한다. 그 외 임무/기하 안전 단언은 유지한다. 사용자 지도는 소스에 추가하지 않는다.

이 문서는 독립 Astra 검토와 브라우저 종단간 검증을 대신하지 않는다. 이 변경에서 push/commit/deploy/cloud API를 실행하지 않는다.
