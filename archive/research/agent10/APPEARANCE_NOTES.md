| 구분 | 작업 결과 |
|---|---|
| 작업 위치 | `메카닉 (2)/mechanic-hub/app/scene-appearance.ts` 새 파일만 작성 |
| 기체 | 녹색 기판, 노란 4개 롤러 바퀴, 전면 카메라 렌즈, 전면 방향 표식으로 라즈봇 V2를 연상시키는 2D 근사 외형 |
| 산업 객체 | 다단 선반 랙, 테이프 상자, 벽돌 무늬 벽, 목재 슬랫 팔레트, 주황 콘 |
| 사람·물품 | 머리·몸통·팔·다리와 조끼가 있는 작업자, 반구 안전모 |
| 시설·표지 | 번개·접점 충전소, 사선 해치 통로 예약, 대기점 표시, 양문 엘리베이터, 가상 QR 무늬 |

| CPU 환경 | 기존 Canvas 2D에 절차적으로 그림. WebGL, GPU, 외부 이미지·모델 로더 없이 동작 |
| 속도 트랙바 | 5번 담당에게 적용 대상·단위·현재값·가상 주행 속도 설명·접근성 이름·대비 개선 요청 |
| 검증 | 복사본에서 `npx tsc --noEmit --incremental false` 종료 코드 0. 실제 화면 통합 확인은 주 에이전트와 5번 담당에게 인계 |

## 통합 인터페이스

```ts
drawEntityAppearance(ctx, entity, {x, y, w, h}, {selected, color});
// 기체의 기존 translate/rotate 호출 안에서 사용. +X가 전면.
drawRobotAppearance(ctx, {x, y, w, h}, {selected, color});
```

5번 담당이 기존 SceneLab의 사각형 그리기 부분에 위 함수를 연결합니다. 이름·선택 핸들은 기존 편집 코드에서 계속 담당합니다. `drawFrontAppearance`는 선택적 투영 장식용이며 기존 raycast 카메라에는 자동 적용하지 않습니다.

## 외형의 의미와 제한

- CAD 데이터셋, 제조사 검증 모델 또는 실물 치수 모델이 아닙니다. 사용자가 종류를 이해하기 쉽게 만든 설명용 기호입니다.
- QR 무늬는 실제 디코딩 가능한 QR이 아닙니다. 라벨·도움말에서 가상 표지임을 유지해야 합니다.
- 2D 외형 개선만으로 실제 Unity·CARLA·Gazebo 모델이나 실제 카메라 연결이 추가되지 않습니다.
- 투영된 웹 카메라의 raycast 구조는 수정하지 않았습니다. 지도 외형과 카메라의 원근 실루엣 개선은 서로 다른 범위입니다.
- 모든 도형은 기존 사각형으로 clip하여 객체 크기 변경에도 외형이 함께 맞춰집니다.

## 다운로드 및 라이선스

외부 데이터셋·이미지·3D 모델을 다운로드하거나 사용하지 않았습니다. 이번 코드로 직접 생성하는 도형만 사용하므로 외부 에셋의 배포 라이선스는 발생하지 않습니다. 대형 모델 다운로드 및 별도 설치도 없습니다.

## 보호 범위

원본 프로젝트, 현재 배포 사이트, 운영 DB, 외부 서비스, Git 원격은 수정·접속하지 않았습니다. 기존 SceneLab/CSS 파일은 5번 담당 소유로 직접 수정하지 않았습니다. 보고서는 복사본 연구 디렉터리에만 저장했습니다.
