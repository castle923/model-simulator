# 10번 — 정면 웹 카메라 객체 디테일

| 항목 | 개선 내용 |
|---|---|
| 기체 | 지도 위에서 본 기체와 별개로, 정면 카메라용 바퀴·기판·차체·카메라 지지대·렌즈·전면 센서 표현 |
| 작업자 | 머리·얼굴·팔·다리·신발과 조끼 반사띠. 외곽 여백을 불필요하게 사각형으로 칠하지 않음 |
| 안전모·콘 | 반구와 테두리, 원뿔과 흰색 띠·바닥판 |
| 랙·상자·팔레트 | 선반 3단·지지대·적재 상자, 상자 테이프와 라벨, 목재 구조 |
| 충전소·엘리베이터 | 표시창·번개·접점, 양문·상하 표시 |
| 벽·QR | 벽돌 줄눈, 실제 디코딩용이 아닌 가상 QR 표지 |
| 통로·대기점 | 카메라 내 물체로 세우지 않음. 기존 지도 표지는 유지 |
| 계산 방식 | Canvas 2D, WebGL·이미지·모델 로더 없음 |

## 통합 계약

`drawFrontAppearance(ctx, kind, fullProjectedRect, color?)`는 **전체 객체의 투영 사각형**을 입력받습니다. 함수 자체는 사각형 밖으로 그림이 나가지 않도록 clip합니다. 기체 위치·방향, 객체 좌표·크기, 거리에 따른 투영 크기는 5번 담당의 기존 카메라 투영 코드에서 계산합니다.

가려진 조각의 폭을 함수에 전달해 외형 전체를 조각으로 압축하면 안 됩니다. 처음에는 가장 가까운 ray column clip을 제안했으나, 5번 담당은 낮은 안전모 뒤의 작업자 상체도 보이도록 **전체 투영 사각형을 먼 객체부터 가까운 객체 순서로 그리는 방식**을 선택했습니다. 실제 가림·거리·크기 표현은 최종 화면 검증 대상입니다.

## 검증 및 범위

- 작성 파일은 복사본 `app/scene-appearance.ts`의 정면 그리기 부분입니다. 기존 지도 helper와 core·경로·충돌 데이터는 수정하지 않았습니다.
- 1차 `tsc`에서 본 helper 오류는 없었습니다. 동시 작성 중인 `lib/front-projection.ts`의 `number` `x/y` 참조 오류 2건은 5번 담당이 수정했습니다. 수정 후 10번이 `npx tsc --noEmit --incremental false`를 다시 실행하여 종료 코드 0을 확인했습니다. 최종 빌드·화면 검증은 주 에이전트 담당입니다.
- 외형은 설명용 2D 근사이며 실제 3D/CAD 모델이 아닙니다. Unity·CARLA·Gazebo 실제 카메라 연결을 의미하지 않습니다.
- 사용자 기존 탭을 조작하지 않았고, 운영 사이트·DB·원본·배포는 변경하지 않았습니다.
- 외부 다운로드·설치 없음.
